ℹ️ How to Use
  1. Upload two SVG files using the upload buttons
  2. Adjust animation parameters using the controls
  3. Click "Play" to start the morphing animation
  4. Use the progress slider to scrub through the animation
  5. Enable "Loop" for continuous animation
  6. Enable "Reverse on Loop" for ping-pong effect

Tips:

  • Best results with SVGs that have similar path complexity
  • LAB color space provides more natural color transitions
  • Lower path precision = smoother paths but less detail
  • Higher path precision = more accurate but potentially choppy
